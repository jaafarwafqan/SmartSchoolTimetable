# Decisions pending owner confirmation (Phase 2)

Each entry was taken autonomously while the owner was away (Phase 2 autonomy protocol 0.5). Each one is the safest option that keeps the approved architecture. Each says how to change it.

| # | Date | Decision | Alternatives | Reason | How to change |
|---|---|---|---|---|---|
| 1 | 2026-10-03 | **Shifts, lesson periods, stages and sections belong to an academic year.** Subjects, teachers and the school profile are global. | Everything global; everything per year | Spec 2.2 says a new year is created "by copying the structure of the previous one (shifts, periods, stages, sections)", which only makes sense if these are per year. Teachers and subjects persist across years. | Remove `AcademicYearId` from `Shift`/`Stage` (migration) and drop the copy option. |
| 2 | 2026-10-03 | **"Active flag" and "soft archive" are one concept:** `IsArchived` (+ `ArchivedAt`). Archived records are hidden unless "include archived" is chosen; restoring makes them active again. | Separate `IsActive` and `IsArchived` flags | Two overlapping flags would let a record be "active but archived". Spec 2.7–2.10 ask for an active flag, and section 1 asks for soft archive. | Add a separate flag and filter (migration + UI toggle). |
| 3 | 2026-10-03 | **Weekday numbering is ISO-8601: 1 = Monday … 7 = Sunday.** Defaults: working days Sunday–Thursday (7,1,2,3,4), week start Sunday (7). | 1 = Sunday; .NET `DayOfWeek` (0 = Sunday) | ISO numbering is unambiguous and matches spec 2.3 "weekdays (1-7)". Display order follows the "week start day" setting. | Change `Weekday` mapping in Domain and the UI day list (no data migration if done before real use). |
| 4 | 2026-10-03 | **Blocked periods (subjects and teachers) reference the lesson number** (1st lesson, 2nd lesson…, breaks excluded), not the row number in the periods table. | Row number including breaks | Breaks cannot be taught, so blocking a break is meaningless. Lesson numbers stay stable if a break is inserted. | Store row numbers instead and adjust validation. |
| 5 | 2026-10-03 | **Teacher limits are validated against the current year's largest shift:** max per day ≤ the most lessons any shift has per day; max per week ≤ working days × that number. If no shift or period exists yet, limits are accepted and validated when structure exists (shown as a warning). | Validate per assigned shift (teachers have no shift in Phase 2) | Teachers are global and not yet assigned to a shift; this is the safest upper bound. | Add a teacher↔shift link in Phase 3. |
| 6 | 2026-10-03 | **Dashboard "capacity gaps" = sections whose computed weekly capacity is 0** (their shift has no lessons, or there are no working days). | Workload vs capacity | Workload is Phase 3. Only real, computable data is shown (no fake statistics). | Redefine when Phase 3 workload exists. |
| 7 | 2026-10-03 | **Time zones are chosen from a fixed list of IANA zones** (Asia/Baghdad default; Gulf, Levant, Egypt, Iran, Turkey and UTC). | Free text | Prevents invalid IDs; works offline with .NET ICU time zone data. | Extend the list in `SchoolProfileRules.SupportedTimeZones`. |
| 8 | 2026-10-03 | **Until Phase 2 data exists, numerals default to Arabic-Indic and the calendar display to Gregorian** (the defaults of a new school profile). | Western digits | Matches the Arabic-first UI. The school setting overrides it immediately. | Change the defaults in `SchoolProfile.CreateDefault`. |
| 9 | 2026-10-03 | **Bell tones are synthesized with Web Audio and play only on explicit preview.** | Bundled sound files; scheduled ringing in Phase 2 | Avoid audio assets and licensing; live ringing is Phase 7. | Replace tone preview implementation and revise ADR 0018. || 10 | 2026-10-04 | **Display order of shifts and stages is a sort key, not unique.** Ties sort by name. This replaces the unique indexes from 2B and from the owner's 2C changes (migration `Phase2CDisplayOrderIndexes`). | Keep unique orders with a dedicated error code | A duplicate order was reported as a duplicate *name*, which is misleading. Unique orders also force a temporary value when swapping two rows. The intent (a clear, owner-controlled order) is kept. | Make the two indexes unique again in `SchoolSetupConfiguration` (new migration) and add a `DUPLICATE_ORDER` code. |
| 11 | 2026-10-04 | **A section cannot be created in, or restored into, an archived stage** (`STAGE_ARCHIVED`, 409). Hard delete: a stage only while it has no sections; a section always (nothing references it before Phase 3); a shift only while no section uses it. | Allow restore and hide the section; cascade-delete sections | Keeps every visible section inside a visible stage, and never deletes data silently. | Change the checks in `StagesSectionsService` and `TimetableStructureService.DeleteShiftAsync`. |
| 12 | 2026-10-04 | **Blocked periods (subjects now, teachers in 2E) must lie inside the current schedule grid:** a working day, and a lesson number from 1 to the most lessons per day of any shift in the current year. With no periods defined, no slot can be blocked. The UI drops slots that fell outside the grid (after days or periods changed) and warns before saving. | Accept 1–12 when no periods exist; keep out-of-grid slots | Rejecting invalid references is the spec rule (2.10) and the safest. Periods are defined before subjects in the setup checklist. | Relax `ScheduleGrid.Contains` (Domain) and `slotsInGrid` (UI). |
